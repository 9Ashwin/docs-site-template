# Web 端

这一页是客户端类页面的骨架：说明入口、主要页面与操作路径。

## 入口 {#entry}

浏览器打开部署地址：根路径是官网首页，`/docs/` 是文档站。两者共用顶栏、深浅色与品牌样式。

## 页面结构 {#pages}

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 品牌、分类导航、搜索、深浅色切换、GitHub |
| 侧边栏 | 按分类分组的页面列表，随滚动定位当前项 |
| 正文 | Markdown 渲染结果，右侧是本页目录 |

## 交互 {#interaction}

- 深浅色偏好在官网与文档间共享，并跟随系统默认。
- 搜索框快捷键 `⌘K` / `Ctrl+K`。
- 窄屏下顶栏变成抽屉导航，侧边栏由左下角按钮打开。
