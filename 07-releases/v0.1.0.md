# v0.1.0 版本说明

**发布日期**：2026-01-01

模板的首个版本。换成自己的项目后，把这个文件当作版本页的格式示例：每版一页，文件名就是版本号，侧边栏按版本号倒序排列。

## 本版内容 {#highlights}

- 官网首页 + 文档站一次构建、一份产物。
- 文档站支持分类侧边栏、中文本地搜索、目录页与深浅色。
- 构建前置检查：站内链接、锚点、Mermaid 语法。
- 产物检查：资源路径、锚点存在性、截图尺寸预留。
- 部署：GitHub Pages（含子路径）、Docker、Nginx。

## 升级注意 {#upgrade}

- 无破坏性变更。
- 首次使用需按 [模板介绍](../01-getting-started/01-introduction.md#first-run) 修改站点配置。
